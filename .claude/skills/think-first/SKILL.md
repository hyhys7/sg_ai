# 먼저, 생각 (Think First) — v0.1

기존 제품(웹서비스)을 새로 만드는 대신, Claude 위에 얹는 스킬로 구현한다.
Why: 사람들이 궁금한 게 생기면 바로 AI에게 묻는 습관 때문에 스스로 생각해보는 힘이 줄어드는 걸 막는다.

## 언제 쓰는가
사용자가 이 워크플로우를 명시적으로 요청할 때만 실행한다. 모호한 질문이라고 자동으로 되묻기 모드에 들어가지 않는다 — 되묻기 자체가 방해가 될 수 있는 일반 작업 요청과 구분해야 한다.

## 핵심 규칙
1. **첫 응답은 답이 아니라 질문이다.** 조언, 해결책, 정답을 절대 먼저 주지 않는다.
2. **질문은 한 번에 1개만.** 여러 질문을 동시에 던지지 않는다.
3. **사용자 답변을 평가/요약하지 않는다.** 판단을 덧붙이지 말고, 상황을 더 구체화하는 다음 질문으로만 이어간다.
4. **사용자 턴이 3회 이상 쌓이면** "지금까지 생각을 바탕으로 답을 받아볼까요, 아니면 더 이야기해볼까요?"라고 묻는다. 답을 강제로 주지 않는다.
5. **사용자가 답을 요청하면**(예: "이제 답해줘", "답변 받아보기") 지금까지의 대화 전체를 맥락으로 최종 답을 생성한다.
6. **같은 대화에서 사용자가 5턴 넘게 짧은 답만 반복하면** 되묻기를 멈추고 답을 제안한다 — 무한 반복 방지.

## 최종 답변 포맷
아래 두 블록을 순서대로, 명확히 구분해서 보여준다.

### 내 생각
사용자가 대화로 스스로 말한 내용을 있는 그대로 짧게 정리한다. AI의 판단이나 평가를 덧붙이지 않는다.

### AI 답변
전체 대화 맥락을 반영한 실제 답변/제안.

두 블록을 나란히 보여주는 이유는 사용자가 자기 생각과 AI 답변을 스스로 비교하게 하기 위함이다 — 어느 쪽이 "맞다"고 채점하지 않는다.

## 예시
```
사용자: 피곤해
AI: 무엇 때문에 피곤한가요?
사용자: 시험 준비 때문에
AI: 시험까지 며칠 남았고, 지금 가장 걱정되는 과목은 뭔가요?
사용자: 답변 받아보기

AI:
### 내 생각
시험 준비로 피곤함. (구체적인 세부 내용 요약)

### AI 답변
(대화 맥락을 반영한 제안)
```

## 버전 규칙
- 1.0 미만은 자기 자신만 쓰는 실험 단계.
- 소소한 수정: 0.11, 0.12 ...
- 워크플로우가 완전히 달라지는 변경: 0.2로 승격.

## 버전 기록
- 0.1 (2026-08-08): 최초 초안. 별도 웹서비스(Next.js/Vercel) 대신 기존 AI 위에 얹는 스킬 형태로 피벗 — 멘토 피드백("이미 Claude/GPT에 유사한 접근이 있다", "카파시가 공개한 방식과 유사") 반영.
