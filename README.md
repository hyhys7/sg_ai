# sgprojectastar

AI에게 곧장 답을 구하기 전에, 스스로 생각할 기회를 돌려주는 되묻기 대화형 웹서비스입니다.

## Why — 왜 만드는가

무언가 궁금할 때 바로 AI에게 묻는 것이 습관이 되면서, 스스로 생각해보는 힘과 의지가 점점 줄어드는 현상을 막고 싶습니다.

## What — 무엇을 하는가

- 사용자가 질문을 던지면 AI는 곧바로 답하지 않고 **되묻는다.**
- 짧고 성의 없이 던진 질문이라도, AI의 되물음을 통해 사용자가 상황과 생각을 스스로 구체화하도록 유도한다.
- 몇 차례의 대화가 충분히 쌓이면, 사용자가 직접 **"답변 받아보기"** 버튼을 눌러야 AI가 답을 준다.
- 그 순간, 사용자가 대화를 통해 쌓아온 자신의 생각과 AI의 답변을 **나란히 비교**해서 보여준다.
- 평가나 점수는 없다.
- 회원가입 없이 링크 하나로 누구나 바로 사용할 수 있다.

## How — 사용 흐름

1. 회원가입 없이 링크로 접속한다.
2. 궁금한 것을 질문으로 입력한다.
3. AI가 즉답 대신 되묻고, 사용자는 대화를 이어가며 생각을 구체화한다.
4. 대화가 충분히 쌓이면 "답변 받아보기"를 누른다.
5. 사용자 자신의 생각과 AI의 답변이 나란히 제시되어 스스로 비교해볼 수 있다.

## 기술 스택

- **Frontend / Server**: [Next.js](https://nextjs.org/)
- **AI**: [Claude API](https://platform.claude.com/) (Anthropic) — 되묻는 대화 및 최종 답변 생성

## 설치 및 실행

```bash
npm install
```

`.env.local` 파일에 Claude API 키를 설정합니다.

```bash
ANTHROPIC_API_KEY=your-api-key
```

```bash
npm run dev
```
